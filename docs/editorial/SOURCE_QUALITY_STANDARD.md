# Estándar de evidencia y fuentes

## Jerarquía de fuentes

1. **Investigación primaria y revisiones sistemáticas:** DOI, PubMed Central, editor de revista o repositorio universitario.
2. **Organismos públicos o intergubernamentales:** NASA, NOAA, USGS, Smithsonian, IUCN, IPCC, UNESCO, servicios meteorológicos nacionales.
3. **Universidades, museos y sociedades científicas:** cuando describen su investigación o colecciones.
4. **Medios científicos:** solo para contexto; nunca como única fuente de una afirmación técnica.

No se usan como fuente editorial: textos generados por IA, agregadores sin autor, páginas SEO, redes sociales ni resultados de búsqueda.

## Reglas de trazabilidad

- Cada URL se abre y se comprueba antes de incluirla.
- Las cifras, fechas, estados de conservación y afirmaciones de salud necesitan una fuente específica y, cuando sea posible, una fecha de acceso.
- Si la evidencia es incierta o controvertida, el artículo debe decirlo explícitamente y representar más de una fuente.
- Una lista de nombres de revistas no equivale a bibliografía. Cada referencia debe enlazarse.
- No se inventan DOI, autores, afiliaciones, fechas de revisión, licencias ni citas.

## Fuentes vivas

Los temas con cambios frecuentes —estado de conservación, clima, brotes, datos de población y recomendaciones sanitarias— se revisan cada 6–12 meses. Una modificación solo actualiza `reviewedDate` si cambia de forma material el contenido o sus fuentes.
