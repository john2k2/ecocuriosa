> Pregunta del lector: ¿Cómo se pasa de pares de bases a una identificación taxonómica sin confundir similitud genética con prueba?

Una secuencia de ADN puede compararse con registros de referencia para buscar una coincidencia taxonómica. El paso útil para el lector no es tratar esa coincidencia como una identificación infalible, sino separar la señal molecular de la evidencia adicional que confirma qué organismo estaba presente.

El brief propone explicar el recorrido pares de bases → coincidencia → nombre taxonómico y mostrar dónde aparecen las incertidumbres: calidad de la muestra, cobertura de referencias, umbral de similitud y contexto ecológico. La búsqueda puede ayudar a formular una identificación, pero no convierte automáticamente una coincidencia en un censo de distribución o abundancia.

El programa de trabajo de GBIF se incorpora como contexto de desarrollo para metabarcoding, eDNA y datos marinos, no como prueba de resultados ya alcanzados.
