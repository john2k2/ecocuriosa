## Reglas para automatización

1. Luna puede consultar esta lista para hallar candidatas; no puede convertirla automáticamente en citas.
2. El editor comprueba URL, entidad, fecha, licencia y correspondencia con la afirmación antes de completar `sources`.
3. Para una afirmación de salud, conservación, récord biológico o cifra exacta, se prefiere la fuente primaria o el organismo responsable sobre una ficha secundaria.
4. Las fuentes de imágenes se guardan con URL del activo, autor, licencia y crédito; una página general no es prueba de licencia para un activo concreto.
